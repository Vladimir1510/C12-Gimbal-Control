# C12 Gimbal Control

Android-застосунок для пульта **SIYI UniRC 7**. Він керує підвісом і зумом камери **C12** колесами та кнопками пульта. UART застосунок не відкриває: канали пульта читає через службу UniGCS, а команди камері надсилає по UDP.

Перевірено на реальному обладнанні: UniRC 7 (Android 13) + C12.

## Керування

| Контрол пульта | Дія |
|---|---|
| Колесо **CH6** | нахил камери вгору/вниз; швидкість залежить від відхилення колеса (до 50) |
| Колесо **CH7** | зум: збільшення/зменшення, крок кожні 90 мс |
| Кнопка **CH12** | центрувати підвіс |
| Кнопка **CH13** | опустити камеру на −90° |
| Кнопка **R1 (CH14)** | тепловий фільтр — перемикає палітру по колу (кожне натискання наступна) |

Мертва зона коліс — ±45 від центру (1500). Призначення каналів задаються константами `CH_*` у `GimbalService.kt`.

## Використання

1. Встановіть APK і один раз відкрийте застосунок.
2. Дайте дозволи:
   - **сповіщення** — запит з'явиться при першому запуску;
   - **«поверх усіх додатків»** — кнопкою на головному екрані.
3. З'явиться плаваюча кнопка **C12** поверх усіх застосунків, зокрема UniGCS:
   - **зелена** — керування працює, **червона** — вимкнене, **сіра** — ще немає даних з пульта;
   - **дотик** — увімкнути/вимкнути керування;
   - **перетягування** — перемістити кнопку;
   - **утримання** — відкрити застосунок.
4. Повністю вимкнути керування можна кнопкою «Закрити» у сповіщенні.

Після ввімкнення пульта застосунок запускається сам, але керування лишається **вимкненим**, доки ви не торкнетеся кнопки.

На головному екрані видно:
- стан зв'язку з пультом і мережі камери;
- положення коліс нахилу та зуму;
- останню надіслану команду;
- кнопки «Центр», «Вниз 90°» і «Фільтр» (перемикання теплової палітри по колу).

Внизу — згорнутий розділ «Діагностика» з журналом подій.

## Як це працює

```
Пульт ──UART──► UniGCS (RemoteControlService) ──Binder──► GimbalService ──UDP──► C12
                                                     (цей застосунок)    192.168.144.108:5000
```

**Канали пульта.** Застосунок під'єднується до експортованої служби `biz.siyi.remotecontrol/biz.siyi.pilot.rcuservice.RemoteControlService` (інтерфейс `IRemoteControl`):
- транзакція 1 реєструє наш колбек `IRemoteCallback`, транзакція 2 його знімає;
- транзакція 40 вмикає потік каналів, транзакція 41 вимикає;
- канали приходять колбеком з кодом 8 як `List<ChannelValue>` — назва `CHANNEL_1..16` і значення 1050–1950.

Кадри приходять **лише при зміні** значень, тому поточна швидкість нахилу повторюється кожні 200 мс, поки колесо відхилене.

Цей контракт отримано декомпіляцією UniGCS. Після оновлення UniGCS номери транзакцій можуть змінитися.

**Команди камері.** Це ASCII-рядки по UDP на `192.168.144.108:5000`, контрольна сума — сума байтів за модулем 256 у вигляді двох hex-символів (`C12Client.kt`):

| Дія | Команда |
|---|---|
| Стоп | `#TPUG2wPTZ00` |
| Центр | `#TPUG2wPTZ05` |
| Нахил зі швидкістю | `#TPUG2wGSP` + швидкість (hex-байт зі знаком) |
| Нахил на кут | `#TPUG6wGAP` + кут×100 (4 hex) + швидкість 1..30 (2 hex) |
| Зум + / − | `#TPUD2wDZM0A` / `#TPUD2wDZM0B` |
| Тепловий фільтр | `#TPUD2wIMG` + код палітри (hex-байт) |

Камера на команди не відповідає.

**Теплові палітри (IMG).** Кнопка R1 / екранна кнопка «Фільтр» перемикають 11 палітр по колу (коди з C12 rcsdk, значення `02` не використовується): `01` біла гаряча, `03` сепія, `04` залізо, `05` райдуга, `06` ніч, `07` аврора, `08` червона гаряча, `09` джунглі, `0A` медична, `0B` чорна гаряча, `0C` сяйво. Список і порядок — у `C12Protocol.PALETTES`. Перемикання видиме↔теплове (EO/IR) окремої UDP-команди не має — воно задається вибором RTSP-потоку (видиме `stream=0/1` на порту 554, теплове `stream=2` на 555).

**Безпека.** STOP надсилається, коли:
- вимикається керування;
- застосунок закривається;
- зникає зв'язок зі службою UniGCS.

## Важливо

- Мережа камери на пульті — інтерфейс `usb0` (`192.168.144.20`). Вона **існує лише тоді, коли USB-C пульта не підключений до комп'ютера**. Для налагодження з камерою використовуйте adb через Wi-Fi.
- Потрібен встановлений UniGCS (`biz.siyi.remotecontrol`).
- Протокол C12 взято з робочих прикладів, а не з офіційного SDK. Нові команди спершу перевіряйте на землі.

## Структура

- `GimbalService.kt` — фоновий сервіс: канали з UniGCS, логіка керування, плаваюча кнопка, сповіщення.
- `C12Client.kt` — формування команд C12 і надсилання по UDP.
- `MainActivity.kt` — головний екран, статус і діагностика (сканування input-пристроїв і пакетів, журнал).
- `BootReceiver.kt` — автозапуск сервісу після ввімкнення пульта.

## Збірка

**GitHub Actions:** пуш у `main` або `taras`, або Actions → Build Android APK → Run workflow. Готовий APK — в артефакті `C12-Gimbal-Control-debug`.

**Локально** (JDK 17, Gradle 8.9, Android SDK з platform 35):

```
gradle assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
